# Scoped security review (portfolio demo)
Public mode uses signed random per-session cookies, server-enforced 24h expiry, Secure/HttpOnly/SameSite Strict, session-scoped SQL queries and parameterization. Upload limits: TXT/Markdown, 1 MB, 10 docs/100 chunks per session; global caps. Public write rate 40/minute/session, 180/minute/global; separate model budget. Root CSP hashes inline script, blocks framing, third-party connections and object embedding; other headers include nosniff, HSTS, referrer and permissions policies. No external provider requests without explicit mode selection/consent. Provider endpoint restricted in public mode. Semantic rank IDs validated, sources treated as untrusted; prompt injection remains possible and citations are not proof of truth. Browser history is in memory, clears on reload, can be cleared manually; not sent automatically. Test data only. Free hosting restarts can reset usage and sessions; cleanup on subsequent traffic, no durable privacy deletion guarantee. No formal independent penetration test, identity authentication, DDoS protection or production compliance certification. Do not upload confidential material. Review dependencies and use independent security assessment before production use.
